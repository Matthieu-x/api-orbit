Documentación

Referencia de los endpoints disponibles en Orbit API. Todas las rutas usan /api/v1 y, salvo indicación contraria, requieren una API key válida.

AutenticaciónSearchDownloadPinterestOrbit IAToolsErrores

Autenticación

Puedes enviar la clave como parámetro apikey o mediante el header X-API-Key.

GET /api/v1/search?apikey=ORBIT-XXXXXXXX&query=lofi
X-API-Key: ORBIT-XXXXXXXX

Las cuentas Free tienen un límite diario. Los endpoints marcados como VIP requieren acceso VIP.

Search

GET/api/v1/search

Busca videos en YouTube. El parámetro query admite hasta 100 caracteres.

querystring · req.Texto de búsqueda.
GET /api/v1/search?apikey=ORBIT-XXXXXXXX&query=lofi

Download

GET/api/v1/download/ytaudio

Obtiene audio desde una URL.

urlstring · req.URL del contenido.
GET /api/v1/download/ytaudio?apikey=ORBIT-XXXXXXXX&url=https%3A%2F%2F...
GET/api/v1/download/ytvideo

Descarga video. Requiere VIP.

urlstring · req.URL del video.
qualitystringCalidad solicitada. Por defecto: 720.
GET/api/v1/download/tiktok

Procesa una URL de TikTok.

urlstring · req.URL de TikTok.
GET/api/v1/download/aptoide

Busca aplicaciones en Aptoide y permite descarga. Requiere VIP.

querystringNombre o término de búsqueda.
packagestringNombre de paquete.
downloadstringUsa true para solicitar descarga.
GET/api/v1/download/fdroid

Busca o descarga paquetes de F-Droid. Requiere VIP.

querystringTexto de búsqueda.
packagestringPaquete concreto.
downloadstringUsa true para descargar.

Pinterest

GET/api/v1/pinterest

Busca contenido en Pinterest.

querystring · req.Texto de búsqueda, máximo 100 caracteres.
typestringTipo opcional de búsqueda.
GET /api/v1/pinterest?apikey=ORBIT-XXXXXXXX&query=anime

Orbit IA

GET/api/v1/ia

Envía una consulta a Orbit IA. Requiere VIP.

textstring · req.Texto que quieres consultar.
promptSystemstringPrompt de sistema opcional.
GET /api/v1/ia?apikey=ORBIT-XXXXXXXX&text=Hola

Tools

GET/api/v1/tools/qr

Genera un código QR.

text / urlstring · req.Contenido del QR, máximo 2000 caracteres.
formatstringimage, json o base64.
sizenumberTamaño opcional.
dark/lightstringColores opcionales del QR.
GET /api/v1/tools/qr?apikey=ORBIT-XXXXXXXX&text=Hola&format=json

Errores

Orbit responde JSON cuando una solicitud no puede procesarse. Los códigos habituales son 400 para parámetros inválidos, 401 para API key ausente o inválida, 403 para endpoints VIP sin acceso y 5xx para errores de procesamiento.
