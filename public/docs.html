Referencia API

Documentación

Guía rápida de los endpoints disponibles en Orbit API. Todas las rutas usan /api/v1 y aceptan la API key mediante apikey o el header X-API-Key.

Autenticación y límites

Cada solicitud autenticada consume una solicitud del cupo diario. Las cuentas Free tienen 100 solicitudes al día. Los endpoints marcados como VIP requieren una suscripción VIP activa.

GET /api/v1/search?apikey=ORBIT-XXXXXXXXXX&query=lofi
