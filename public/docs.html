Documentación

Referencia de los endpoints disponibles en Orbit API, sus parámetros y la forma correcta de realizar solicitudes.

Autenticación

Los endpoints protegidos utilizan tu API key. Puedes enviarla como parámetro apikey o mediante el header X-API-Key.

GET /api/v1/search?apikey=TU_API_KEY&query=lofi # También puedes usar: X-API-Key: TU_API_KEY

Límites

Las solicitudes autenticadas consumen el límite diario asociado a tu cuenta. Las funciones VIP requieren una cuenta con acceso VIP.

Search

Busca contenido en YouTube. El parámetro query es obligatorio y admite hasta 100 caracteres.

GET /api/v1/search?apikey=TU_API_KEY&query=lofi
MétodoParámetroDescripción

Pinterest

Busca contenido de Pinterest. Requiere query; también puedes indicar type cuando el endpoint lo admita.

GET /api/v1/pinterest?apikey=TU_API_KEY&query=wallpaper GET /api/v1/pinterest?apikey=TU_API_KEY&query=wallpaper&type=image

IA

Endpoint de inteligencia artificial disponible para cuentas con acceso VIP.

GET /api/v1/ia?apikey=TU_API_KEY&text=Hola

Admite text como parámetro obligatorio y promptSystem como parámetro opcional.

Seguridad por IP

Cada API key queda ligada a la IP desde la que se usa. Esto evita que alguien que consiga tu key la use desde otro lugar: si la IP no coincide, la solicitud se bloquea automáticamente.

Cómo se registra tu IP

  • La primera vez que usas tu API key (o la próxima vez que inicias sesión), tu IP actual queda registrada como la dueña de la cuenta.
  • Cuentas Free pueden tener 1 IP registrada, que se actualiza sola en cada login.
  • Cuentas VIP y admin pueden registrar hasta 5 IPs a la vez (por ejemplo, tu computadora y el servidor donde corre tu bot).

Si usas tu key en un bot

La IP que se registra es la del servidor donde corre el bot, no la de cada persona que le escribe. Todos los usuarios de tu bot siguen funcionando igual, sin importar desde dónde te escriban.

Página "Configurar IP"

Desde el dashboard, en Configurar IP, puedes ver tu IP actual y restablecerla si cambiaste de red. Las cuentas VIP y admin además pueden agregar o quitar IPs manualmente.

Respuesta cuando una IP no coincide

HTTP 403 { "ok": false, "ip_blocked": true, "error": "Esta API key esta restringida a otra IP. Si eres el dueno, vuelve a iniciar sesion o restablece tu IP desde el dashboard." }
