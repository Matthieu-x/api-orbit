Orbit IP

Tu Orbit IP es una segunda credencial para tu API key. Tiene formato de IPv4 privada, pero no representa tu IP real. Puedes cambiar de Wi-Fi, datos móviles o servidor sin que Orbit te bloquee.

Cómo usarla

Envía tu API key y este valor en cada solicitud:

x-api-key: TU_API_KEY
x-orbit-ip: TU_ORBIT_IP

Regenerar Orbit IP

Genera una nueva credencial y deja inutilizada la anterior.
