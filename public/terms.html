Términos de uso

Última actualización: 8 de septiembre de 2026

1. Aceptación

Al crear una cuenta o utilizar Orbit API aceptas estos términos. Si no estás de acuerdo con ellos, no utilices el servicio.

2. Uso permitido

Debes utilizar Orbit API de forma legal y respetando las condiciones de los servicios y plataformas de terceros a los que accedas mediante sus endpoints.

  • No intentes vulnerar, sobrecargar o interferir con la infraestructura de Orbit.
  • No utilices una API key ajena ni compartas claves privadas de otras cuentas.
  • No automatices solicitudes de forma abusiva para evadir límites o controles.
  • Eres responsable del contenido y de las solicitudes realizadas con tu API key.

3. API keys y cuenta

Tu API key debe mantenerse privada. Las solicitudes autenticadas con tu clave se consideran realizadas desde tu cuenta, salvo que Orbit determine que hubo un compromiso o uso no autorizado.

4. Límites y acceso VIP

Las cuentas Free están sujetas a los límites configurados por Orbit. Algunos endpoints requieren acceso VIP. Los límites, disponibilidad y características pueden cambiar para mantener la estabilidad del servicio.

5. Servicios de terceros

Algunos endpoints dependen de servicios o fuentes externas. Orbit no garantiza la disponibilidad permanente, exactitud, velocidad o continuidad de servicios de terceros.

6. Disponibilidad

Orbit API se ofrece según disponibilidad. Pueden producirse mantenimientos, interrupciones, errores o cambios en endpoints sin garantía de disponibilidad permanente.

7. Suspensión

Orbit puede limitar o suspender una cuenta, API key o solicitud cuando exista abuso, incumplimiento de estos términos, riesgo para la infraestructura o uso contrario a la legislación aplicable.

8. Cambios

Estos términos pueden actualizarse cuando sea necesario. La versión publicada en esta página será la referencia vigente.

Usar una API no convierte mágicamente cualquier contenido de Internet en contenido libre de restricciones. Revisa siempre las reglas aplicables al contenido y servicio que estés utilizando.
