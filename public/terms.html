Términos de uso

Condiciones generales para utilizar Orbit API y sus servicios.

1. Aceptación

Al crear una cuenta o utilizar Orbit API aceptas estos términos. Si no estás de acuerdo con ellos, no debes utilizar el servicio.

2. Uso permitido

Orbit API debe utilizarse de forma legal y responsable. No está permitido utilizar el servicio para actividades que infrinjan leyes, derechos de terceros o las reglas de los servicios externos procesados por la API.

3. API keys

Cada cuenta es responsable del uso de su API key. No debes compartirla públicamente ni utilizar claves de otras personas. Orbit puede limitar o revocar el acceso cuando detecte abuso, automatización indebida o uso contrario a estos términos.

4. Límites y acceso VIP

Las cuentas pueden estar sujetas a límites diarios. Determinados endpoints requieren acceso VIP. Los límites, funciones y disponibilidad pueden cambiar para mantener la estabilidad del servicio.

5. Servicios de terceros

Algunos endpoints procesan información procedente de servicios externos. Orbit API no garantiza la disponibilidad permanente, exactitud o continuidad de dichos servicios.

6. Disponibilidad

El servicio puede experimentar mantenimiento, interrupciones o cambios. No se garantiza disponibilidad ininterrumpida ni que todos los endpoints permanezcan sin modificaciones.

7. Suspensión

Una cuenta puede ser suspendida o limitada cuando exista abuso del servicio, uso fraudulento, exceso deliberado de carga o incumplimiento de estos términos.

8. Cambios

Estos términos pueden actualizarse cuando sea necesario. La versión publicada en esta página será la referencia vigente.

9. Contacto

Para consultas relacionadas con el servicio, utiliza los canales de contacto proporcionados por los responsables de Orbit API.
