Reglas de la plataforma

Términos de uso

Última actualización: 8 de septiembre de 2026

1. Uso permitido

Orbit API debe utilizarse de forma legal y responsable. El usuario es responsable de las solicitudes que realice con su cuenta y API key.

2. API keys

La API key es personal. No debes compartirla públicamente ni incluirla en código del lado del cliente cuando eso permita que terceros la extraigan y consuman tu cuota.

3. Límites y disponibilidad

Las cuentas están sujetas a los límites indicados por Orbit. El servicio puede cambiar, actualizar endpoints o presentar interrupciones por mantenimiento, dependencias externas o problemas técnicos.

4. Funciones VIP

Los endpoints VIP solo están disponibles para cuentas con acceso VIP activo, salvo las excepciones administrativas configuradas por la plataforma.

5. Contenido de terceros

Algunos servicios consultan o procesan contenido de plataformas externas. El usuario debe respetar las leyes, licencias, derechos de autor y condiciones aplicables al contenido que utilice.

6. Abuso

No se permite intentar evadir límites, obtener acceso a cuentas ajenas, manipular autenticación, explotar vulnerabilidades o utilizar Orbit para actividades ilícitas.

7. Cambios

Estos términos pueden actualizarse para reflejar cambios en la plataforma. El uso continuado del servicio después de una actualización implica la aceptación de los términos modificados.

8. Contacto y responsabilidad

Orbit se proporciona según su disponibilidad actual. No se garantiza que todos los servicios externos permanezcan disponibles o que una respuesta externa sea siempre correcta.
